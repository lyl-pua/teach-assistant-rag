# 人教版一年级语文上册 · 识字表（节选）与教学建议

> 一年级上册全册要求认识 300 个常用字，会写 100 个。以下选取前 5 单元核心生字，并配教学建议。

## 一、汉语拼音之后的识字重点

### 第 1 单元（识字一）
天地人 你我他 一二三四五 上下 口耳目 手足 站坐

**小提示：**
- "天、地、人"三才思想，可配图+讲故事《盘古开天地》。
- "你我他"人称代词：做"指一指、说一说"游戏。

### 第 2 单元
金木水火土 日月水火 山石田禾 对韵歌

**教学建议：**
1. 联系生活：在教室里找"日（日光灯、日历）、月（课程表月字）"。
2. 象形字溯源：日、月、水、火、山、石、田、禾，画甲骨文→楷书演变卡。
3. 《对韵歌》：云对雨，雪对风；花对树，鸟对虫；山清对水秀，柳绿对桃红。读出节奏。

### 第 3 单元（课文一）
秋 气 了 树 叶 片 大 飞 会 个 的 船 两 头 在 里 看 见 闪 星

**重点字：**
- "了"：多音字（le / liǎo），本课 le。
- "片、个"：量词。
- "看见"：偏旁目字旁=和眼睛有关。

## 二、易错字整理

1. "人 / 入 / 八"：人撇高捺低；入撇低捺高；八分开不相交。
2. "日 / 目"：日瘦、目胖；目=两横。
3. "木 / 本 / 禾"：木+短横=本；木+撇=禾。
4. "大 / 太 / 天"：大加点=太，大加一横=天。
5. "东 / 车"：东 5 画，车 4 画，笔顺不同。

## 三、识字教学方法

### 1. 加一加 / 减一减
- 加一加：日+月=明；女+子=好；口+天=吴。
- 减一减：鸟-点=乌；王-点=玉→（玉减一点是王，反向）。

### 2. 换一换
- "他" 换偏旁 → 她、地、池。
- "清" → 请、情、晴、蜻。

### 3. 字理识字
- 家：宝盖头=房子；豕=猪 → 古代家中养猪。
- 休：人靠着树休息。

### 4. 情境识字
- 教室：黑板、讲台、粉笔、课桌、窗户。
- 家庭：爸爸、妈妈、厨房、客厅。
- 校园：操场、国旗、走廊、花坛。

## 四、识字评价建议
- 每节课留 2-3 分钟"开火车"认读。
- 单元末做"生字过关贴"，认读错字贴到"生字医院"。
- 鼓励亲子共读：带拼音绘本，每日 10 分钟。
