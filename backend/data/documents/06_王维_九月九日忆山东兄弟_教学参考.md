# 王维《九月九日忆山东兄弟》教学参考

## 一、原文
独在异乡为异客，每逢佳节倍思亲。
遥知兄弟登高处，遍插茱萸少一人。

注：
- 九月九日：重阳节（农历九月初九），习俗登高、插茱萸、赏菊、饮菊花酒。
- 山东：华山以东（王维老家蒲州在华山以东），不是现在的山东省。
- 茱萸(zhū yú)：一种香味浓烈的植物，古人认为重阳插茱萸可避邪。

## 二、作者与背景
王维（701—761），字摩诘，唐代著名诗人、画家。苏轼赞他："诗中有画，画中有诗。"

王维 17 岁时独自漂泊在洛阳与长安之间。重阳佳节，客居他乡，想到家乡兄弟们登高插茱萸时一定也会想念自己，于是写下这首诗。其中"每逢佳节倍思亲"成为千古名句。

## 三、逐句解析

### 第 1 句：独在异乡为异客
- "独"：孤独一个人。
- "异乡"：他乡，不是自己的家乡。
- "异客"：他乡的客人。
两个"异"字，强化了陌生、孤独之感。

### 第 2 句：每逢佳节倍思亲
- "逢"：遇到。
- "佳节"：美好的节日。
- "倍"：加倍、更加。
意思：每次遇到美好的节日，对亲人的思念就比平时更加深切。→ 点题名句。

### 第 3 句：遥知兄弟登高处
- "遥知"：在远方想象、推想。
- "登高"：重阳习俗，高处避灾祈福。

### 第 4 句：遍插茱萸少一人
- "遍"：都、全部。
意思：兄弟们头上都插着茱萸登高时，发现就少了"我"一个人。

## 四、写法亮点："反客为主"
一般诗人会写"我想家人"，王维却写"家人想我，因为少了我"，使得思乡之情更曲折、更真挚。这叫"对写法"或"反客为主"。

## 五、教学目标（三年级）

### 知识与技能
1. 认识"忆、异、逢、佳、倍、遥、遍、插、茱、萸"等生字，会写"独、异、佳、倍、遥、遍"6 个生字。
2. 正确、流利、有感情地朗读、背诵古诗。

### 过程与方法
借助注释、插图、想象画面理解诗意，练习用自己的话说说诗的意思。

### 情感态度
体会诗人对家乡亲人的思念，感受"每逢佳节倍思亲"的普遍情感。

## 六、教学流程简案

### 1. 导入（5min）
- 聊佳节：你家过哪些节日？最热闹的是哪个节日？你出过远门吗？当时想家吗？
- 揭题：今天我们学一首重阳节思乡诗《九月九日忆山东兄弟》。

### 2. 初读正音（8min）
- 范读 → 自由读 → 指名读。
- 节奏提示：
  独在/异乡/为异客，每逢/佳节/倍思亲。
  遥知/兄弟/登高处，遍插/茱萸/少一人。

### 3. 精读悟情（18min）
1. 结合注释、质疑解词。
2. 想象画面：
   - 画面 1：王维一个人住在客栈，窗外热闹过节，他____。
   - 画面 2：老家兄弟们戴着茱萸去爬山，忽然有一个兄弟说："____"。
3. 联系生活：当爸爸妈妈出差的时候，你想他们吗？你怎么表达想念？
4. 带着这种感觉再读。

### 4. 积累拓展（7min）
- 背诵大挑战。
- 拓展其他思乡诗名句：
  - 举头望明月，低头思故乡。（李白）
  - 露从今夜白，月是故乡明。（杜甫）
  - 春风又绿江南岸，明月何时照我还。（王安石）

### 5. 作业布置（2min）
- 必做：背给家人听，默写易错字 3 遍。
- 选做：给远方的亲人打个电话或写一段话。
