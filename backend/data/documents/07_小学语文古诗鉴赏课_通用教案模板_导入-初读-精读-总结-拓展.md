## 二、教学目标

### 1. 知识与技能
（1）认识____个生字，会写____个生字；
（2）能正确认读重点词：____、____、____；
（3）正确、流利、有感情地朗读古诗，背诵古诗。

### 2. 过程与方法
（1）借助注释、插图、工具书理解诗句大意；
（2）通过想象画面、比较朗读、角色扮演体会诗情；
（3）学习"读—想—悟—诵"四步古诗鉴赏法。

### 3. 情感态度与价值观
（1）体会诗人____的思想感情；
（2）感受古诗语言之美、意境之美，积累中华优秀传统文化。

---

## 三、教学重点 / 难点

- **重点**：识字写字；朗读背诵；理解诗意。
- **难点**：体会____句的深层含义；体会诗人____的情感。

---

## 四、教学准备
多媒体课件（配乐、插图、作者卡片）；生字卡片；思维导图板书；小奖品。

## 五、教学过程

### 环节一：导入新课（5 分钟）—— 创设情境，激发兴趣
**方法三选一：**

1. **看图猜诗导入**：出示春/夏/秋/冬/月亮/山水/节日图，让学生猜学过的诗。
2. **音乐导入**：播放与主题匹配的音乐（思乡→《思乡曲》；春天→《春晓》曲）。
3. **故事导入**：讲述诗人写此诗的小故事（如《静夜思》旅舍之夜）。

**教师导语示例：**
"同学们，当你离开爸爸妈妈，第一次一个人住在亲戚家的时候，心里会是什么感觉？今天要学的这首诗，就是一位 17 岁的诗人在外地过节时写下的……"

→ 揭示课题：板书课题 + 齐读课题 + 释题。

### 环节二：初读感知（10 分钟）—— 读准读通，整体把握

1. **范读正音**（2 分钟）：教师配乐范读；听读任务：圈出生字、听清停顿。
2. **自由试读**（3 分钟）：借助拼音、同桌互查。
3. **指名读 + 互评**（3 分钟）：字音、节奏、通顺。
4. **齐读正节奏**（2 分钟）：五言 2-3 / 七言 2-2-3 停顿。

### 环节三：精读品悟（18 分钟）—— 抓关键词，想象画面
**结构化四步：**

#### （1）解字词（5 分钟）
- 学生借助注释 + 插图提出不懂的词；
- 小组互助 → 全班交流 → 教师补充（字理、语境、图片）。
- 板书关键词：____ / ____ / ____。

#### （2）说诗意（5 分钟）
- 四人小组：每人说一句的意思（允许不完整）；
- 推荐代表串说全诗；
- 教师给一个"诗意参考"（不要求背）。

#### （3）想画面（4 分钟）
- 提问引导：
  - 这首诗里你看到了哪些景物？
  - 如果让你画一幅画，你会画什么颜色？画什么人？他们在做什么？
  - 你听到了什么声音？感觉到了什么温度？
- 指名描述；教师配合 PPT 出示意境图。

#### （4）悟情感（4 分钟）
- 抓关键词体会：
  - 思乡类：独、异、倍、思……
  - 春景类：喜、闹、碧、醉……
  - 送别类：送、别、愁、孤……
- 替换朗读：重读关键词 → 男女生分读 → 配乐齐读。

### 环节四：总结升华（4 分钟）
- 总结全诗：这首诗写了____景，抒发了____情。
- 背诵大挑战：30 秒试背 → 接龙背 → 齐背。
- 板书归纳："景—情"双线。

### 环节五：拓展延伸（2 分钟）
- **同类诗对比**：主题同/作者同/季节同；
- **生活化迁移**：回家给家人背一背；观察今天的月亮/天气，尝试写两句小诗句；
- **布置作业**（分层）：
  - A 基础：朗读 3 遍 + 背诵 + 生字抄写。
  - B 提高：画一幅诗意画 / 用自己的话写诗意。
  - C 拓展：找一首类似的诗，下节课分享。

## 六、板书设计

```
            《________》
          ［ ］代·________

       景（关键词）        情（关键词）
   ┌─────────────┐   ┌──────────────┐
   │             │   │              │
   │             │   │              │
   └─────────────┘   └──────────────┘

          读 → 想 → 悟 → 诵
```

---

## 七、教学反思（课后填写）

1. 学生是否达到了"有感情朗读 + 背诵"的目标？
2. 哪一环节学生最投入？哪一环节需要调整？
3. 学困生的难点在哪里？下节课如何补救？
4. 拓展内容是否合适？是否可以加一次仿写小诗？
