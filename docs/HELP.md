## 1. 首次使用

### 1.1 访问系统

打开浏览器访问部署地址（例如 `http://your-server/teach/`），首次进入会看到新中式国风界面：墨绿主色调、宣纸纹理、仿宋字体，左上角印章 logo，侧栏 6 个国风图标导航。

### 1.2 配置 API Key（必须）

首次使用前**必须**配置至少一组 API Key，否则 AI 助手与教学工具只能输出结构化模板。

1. 点击侧栏 **⚙️ 设置** 图标（窗棂样式）
2. 在「API Key 配置」区域填写：
   - **DeepSeek API Key**：主 LLM（必填，用于 AI 对话 + 教学工具生成）
   - **智谱 API Key**：Embedding + 兜底 LLM（必填，用于文档向量化）
   - **和风天气 Key**：可选，未填则使用免 key 的 Open-Meteo 主源
3. 点击「测试」按钮，看到 ✅ 已联通 表示配置成功
4. 配置完成后**无需重启服务**，Key 自动热加载

> 📌 **Key 获取地址**：DeepSeek → https://platform.deepseek.com ；智谱 → https://open.bigmodel.cn ；和风 → https://dev.qweather.com（注意选 **Web API Key**，不是 SDK 凭据）

### 1.3 上传第一批教学文档

为了让 AI 助手「真正懂你的教学」，建议先上传 5-10 篇核心文档：

1. 点击侧栏 **📖 阅读** 图标（竹简样式）
2. 点击「上传文档」按钮
3. 支持 PDF / Word (.docx) / TXT / Markdown 格式
4. 上传后系统自动分块（每块 600 字，重叠 100 字）→ 调用智谱 embedding-3 向量化 → 入库 FAISS
5. 状态变为「已入库」即可在 AI 助手中检索引用

> 💡 **推荐上传内容**：课程标准、单元课文、教学参考、古诗鉴赏、班主任工作指南、阅读理解答题技巧

- 05:00-11:00 → 「早上好，刘老师」

- 每天自动刷新，也可手动点击刷新

右上角绿色徽章显示当前累计 Token 消耗，点击查看详情（按模型分组、最近 5 次调用记录、延迟统计）。

## 4. 阅读（知识库管理）

教学助手的核心模块之一，管理所有供 AI 检索的教学文档。

### 4.1 上传文档

1. 点击「上传文档」
2. 选择文件（支持多选）
3. 系统自动完成：
   - 文档解析（PDF / Word / TXT / MD）
   - 文本清洗（去除多余空白、页眉页脚）
   - 分块（600 字 / 100 字重叠，保留语义连续性）
   - 调用智谱 `embedding-3` 生成 2048 维向量
   - 存入 FAISS 索引 + SQLite chunks 表
4. 状态列显示「已入库 N chunks」即成功

### 4.2 文档列表

- 显示文件名、类型、分块数、上传时间、状态
- 可删除单个文档（同时清理向量库与 chunks 表）
- 可按文件名搜索

### 4.3 重建知识库

如果遇到向量库损坏或异常，可点击「重建知识库」：
- 清空当前 FAISS 索引
- 重新读取所有已上传文档
- 重新分块 + 向量化 + 入库
- 耗时取决于文档数量与智谱 API 响应速度（约 10-30 秒/篇）

> ⚠️ 重建期间 AI 助手暂时无法检索，请耐心等待

## 6. AI 助手

基于 RAG 的智能问答，**回答会引用你上传的教学文档作为依据**。

### 6.1 提问

1. 点击「新建会话」
2. 在输入框输入问题，例如：
   - 「三年级上册第一单元《大青树下的小学》如何设计导入环节？」
   - 「小学古诗教学有哪些有效策略？」
   - 「学困生帮扶的具体做法有哪些？」
3. 按 Enter 或点击发送

### 6.2 回答结构

AI 回答包含三部分：
- **正文回答**：基于检索到的文档生成，Markdown 格式渲染
- **参考资料**：列出引用的文档名、片段编号、内容摘要（前 60 字）
- **模型信息**：显示使用的 LLM 模型（如 `deepseek-chat`）

### 6.3 流式输出

回答采用 SSE 流式输出，逐字显示，体验接近 ChatGPT。

### 6.4 会话管理

- 左侧会话列表可切换、删除
- 历史消息持久化存储在 SQLite

### 6.5 提问技巧

✅ **好的提问**（具体、明确、可检索）：
- 「《静夜思》的教学目标应该如何确定？」
- 「小学二年级识字课的导入方法有哪些？」
- 「班主任如何与家长沟通学生成绩下降问题？」

❌ **不太好的提问**（太空泛，检索不到具体文档）：
- 「语文怎么教？」
- 「告诉我所有教学方法」

## 7. 教学工具

一键生成 4 类教学产物，**生成前会先检索知识库相关段落注入 prompt**，降低幻觉并减少 token 消耗。

### 7.1 教案生成（lesson_plan）

1. 填写：学科、年级、单元、主题、教师备注
2. 系统自动检索知识库中相关教学参考
3. 生成 40-45 分钟完整教案，包含：
   - 教学目标（知识/方法/情感三维）
   - 教学重点 / 难点
   - 教学准备
   - 教学过程（导入→初读→精读→巩固→总结→作业，含时间分配 + 师生活动 + 设计意图）
   - 板书设计
   - 教学反思 / 差异化教学建议

### 7.2 课件大纲（courseware）

生成 PPT 课件大纲，按「第 X 页 · 标题 + 要点」格式，包含 12-18 页：封面、目录、情境导入、核心新知（每页 3-5 要点）、互动练习、总结、作业拓展，每页附教师备注。

### 7.3 分层作业（homework）

设计分层作业，总时长 20-30 分钟：
- **A·基础题**（必做，4-6 题，附答案）
- **B·提高题**（选做，2-3 题，附思路提示）
- **C·拓展题**（含跨学科/实践/探究，1-2 题）
- 设计说明：每类对应目标、预估耗时、批改建议

### 7.4 教学小论文（paper）

生成约 3000 字结构的教学研究小论文：摘要、关键词、引言、相关研究、研究设计、主体分析（含课堂案例）、结论与建议、参考文献。

### 7.5 历史记录

所有生成结果持久化存储，可在「历史」中查看、复制 Markdown。

## 9. Token 消耗追踪

### 9.1 徽章

首页右上角绿色徽章实时显示累计 Token 消耗，格式如 `12345 tokens`。

### 9.2 详情弹窗

点击徽章打开详情，显示：
- **总量统计**：调用次数、prompt_tokens、completion_tokens、total_tokens
- **按模型分组**：每个模型的调用次数与 token 消耗
- **最近 5 次调用**：时间、模型、prompt/completion/total tokens、延迟（ms）

### 9.3 数据来源

后端 `rag/generator.py` 在每次 LLM 调用后捕获 `usage` 字段，写入 SQLite `token_usage` 表。前端通过 `/api/stats/tokens` 接口聚合查询。

## 10. 常见问题 FAQ

### Q1：测试 Key 显示「未联通」但数据库里确实有 Key？

**原因**：前端以小写键名保存（`deepseek_api_key`），后端读取大写键名（`DEEPSEEK_API_KEY`），导致不匹配。

**解决**：本项目已通过 `db.py` 中的 `_KEY_NORMALIZE` 字典自动归一化，如仍出现请检查后端日志是否有「Key 归一化」相关警告。

### Q2：上传文档后 AI 助手检索不到？

**可能原因**：
1. 文档未完成向量化（状态不是「已入库」）
2. 智谱 API Key 未配置或失效（embedding 调用失败）
3. 向量库索引损坏

**解决**：
1. 进入「阅读」查看文档状态
2. 检查智谱 Key 是否测试联通
3. 点击「重建知识库」

### Q3：AI 回答出现「后端未配置大模型 API Key」？

**原因**：DeepSeek 和智谱 Key 都未配置或都失效。

**解决**：进入「设置」配置至少一组 Key 并测试通过。

### Q4：天气显示「暂时无法获取」？

**原因**：Open-Meteo 主源暂时不可用，且未配置和风天气 Web API Key。

**解决**：
1. 等待几分钟自动恢复（Open-Meteo 一般很稳定）
2. 或在「设置」配置和风天气 **Web API Key**（注意不是 SDK 凭据）

### Q5：前端修改后页面没变化？

**原因**：浏览器缓存。

**解决**：
1. 强制刷新：`Ctrl + F5`（Windows）/ `Cmd + Shift + R`（Mac）
2. 本项目已加 `?v=2.1.0` 缓存破坏参数，正常情况下无需手动刷新

### Q6：Nginx 部署后访问 `/teach/` 返回 404？

**原因**：Nginx location 配置问题。

**解决**：
1. 确认使用 `^~ /teach/` 修饰符
2. 确认 `alias /opt/teach/frontend/;` 末尾有 `/`
3. 确认 `sites-enabled` 目录无备份文件（含 `default_server` 会冲突）
4. 执行 `nginx -t` 检查语法

### Q7：502 Bad Gateway？

**原因**：后端服务未启动或端口被占用。

**解决**：
1. `systemctl status teach` 查看服务状态
2. `journalctl -u teach -n 50` 查看后端日志
3. `systemctl restart teach` 重启服务
4. 确认端口 8777 未被其他进程占用

### Q8：如何减少 Token 消耗？

1. **教学工具**：填写更具体的「教师备注」，让检索更精准
2. **AI 助手**：top_k 默认 3，可改为 1-2 减少注入的参考文本
3. **避免空泛提问**：具体到课文/单元/年级，检索更精准
4. **重复提问**：使用历史会话而非新建
